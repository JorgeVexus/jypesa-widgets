## fix: preserve slide index on remeasure and fix arrow navigation in slider certificaciones new

### Descripción
Se corrigió una regresión que impedía avanzar o retroceder el slider al hacer clic en las flechas de navegación:

1. **Eliminación del Re-seteo Incondicional de Offset**:
   - `initAll()` reseteaba incondicionalmente el desplazamiento del widget `--gpk-cert-offset` a `"0px"` cada vez que detectaba una re-evaluación del DOM. Esto provocaba que al hacer clic en "Siguiente", el desplazamiento cambiara brevemente y el `MutationObserver` lo regresara instantáneamente al slide 0.
2. **Preservación del Índice del Slide**:
   - Se expuso la función `_gpkCertMeasure` en la instancia del widget para re-medir las dimensiones reteniendo el `state.index` actual, permitiendo que el slider avance normalmente tanto en móvil como en desktop.

## fix: enforce single card on mobile and fix tap controls in slider certificaciones new

### Descripción
Se corrigieron dos problemas críticos en móvil para `widgets/slider certificaciones new/slider-certificaciones.css`:

1. **Una sola tarjeta en móvil**:
   - Se añadió `!important` a todas las reglas de los media queries (tablet `1023px` y móvil `639px`) para que puedan sobreescribir las reglas base que también usan `!important`. Sin esto, `flex: 0 0 33.333% !important` de la regla base siempre ganaba sobre `flex-basis: 100%` del media query.
   - Se cambió `flex-basis` a `flex: 0 0 100% !important` y `flex: 0 0 calc(50%...) !important` para mayor especificidad.
2. **Botones prev/next clickeables en móvil**:
   - Se aumentó el `z-index` de los controles de `1` a `10` con `!important`.
   - Se añadió `touch-action: manipulation !important` y `-webkit-tap-highlight-color: transparent` a los botones para mejorar la respuesta táctil.
   - En móvil, los controles se reposicionaron de `top: 50%` a `bottom: 12px` para evitar que queden detrás de tarjetas altas.
