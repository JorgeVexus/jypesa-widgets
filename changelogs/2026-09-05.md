# Changelog — 2026-09-05

## feat(colecciones-tabs): add bilingual deep linking via URL hash and query param

### Descripción

Se implementó el soporte para navegación directa a pestañas (**Deep Linking**) mediante URL hash (ej. `#estandar`, `#standard`, `#superior`, `#premium`, `#lujo`, `#luxury`) o parámetro URL `?tab=` en el widget `colecciones-tabs.js`, igualando el comportamiento de `hoteleria-tabs.js`:

1. **Soporte de Navegación por Hash y Query Param**:
   - Función `checkUrlHash()` que lee `window.location.hash` o el parámetro `?tab=`.
   - Limpieza y normalización de diacríticos y caracteres especiales con `cleanAlpha()` y `slugify()`.
   - Coincidencia flexible contra el `data-tab` o el texto visible del tab, admitiendo coincidencias exactas o parciales.
   - Activación automática de la pestaña correspondiente y desplazamiento suave (`smooth scroll`) hacia el contenedor del widget.
   - Listener para el evento `hashchange` para responder inmediatamente a clics en enlaces anchor dentro de la misma página o cambios de historial.

2. **Compatibilidad Total Bilingüe (Español / Inglés)**:
   - Funciona de forma transparente tanto en páginas en español como en inglés.
   - Mapeo cruzado de alias (`estandar` $\leftrightarrow$ `standard`, `lujo` $\leftrightarrow$ `luxury`) para abrir la pestaña correcta sin importar si el enlace se redactó en español o inglés.

3. **Pruebas y Demos**:
   - Se agregaron enlaces de prueba de hash en la barra demo de `colecciones-tabs.html`.
   - Se creó la prueba unitaria automatizada en `tests/colecciones-tabs-deep-linking.test.cjs`.
