## feat: add tab sorting capability and canonical order fallback to collection tabs widgets

### Descripción
Se añadió soporte para ordenamiento configurable y automático de pestañas (tabs) en los widgets de colecciones (`colecciones-tabs.js` y `tabs-colecciones-productos.js`):
1. **Orden canónico por defecto**: Si no se define un orden custom, las pestañas se ordenan automáticamente como Estándar → Superior → Premium → Lujo.
2. **Atributo `data-tabs-order`**: Permite definir un orden personalizado desde Webflow/HTML en el contenedor (ej. `data-tabs-order="Estándar, Superior, Premium, Lujo"`).
3. **Orden numérico CMS (`.jypesa-col-order` / `data-col-order`)**: Permite leer un campo numérico del CMS de Webflow para ordenar de menor a mayor.

### Archivos modificados
- **`widgets/colecciones-tabs/colecciones-tabs.js`**
- **`widgets/tabs-colecciones-productos/tabs-colecciones-productos.js`**

## feat: enhance automatic subgroup detection for product variants in tabs-colecciones-productos

### Descripción
Se mejoró la detección automática de subgrupos/filas secundarias de variantes en `tabs-colecciones-productos.js`:
- Si los ítems dentro de una misma pestaña tienen notas olfativas o logos diferentes (ej. *Amapola Negra* vs *Lavanda*), el script los diferencia y crea automáticamente una segunda fila bajo la misma pestaña sin requerir configuraciones complejas.

## feat: add parent tab group support for multi-row sub-collections

### Descripción
Se añadió soporte para agrupación por Pestaña Padre (`.jypesa-tabs-col-tab-group` / `.jypesa-tabs-col-parent-tab`) en `tabs-colecciones-productos.js`:
- Permite que múltiples colecciones independientes en Webflow (ej. *Amapola Negra* y *Lavanda*, cada una con sus notas olfativas propias en el CMS) se agrupen bajo un mismo Tab superior (ej. *Botella 300 ml*), generándose automáticamente como filas separadas dentro de dicha pestaña.
