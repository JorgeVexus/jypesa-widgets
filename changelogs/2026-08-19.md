# Changelog — 2026-08-19

## feat: add header image support, alignment and increased arrow spacing in slider-coleccion-productos

### Descripción

Se mejoró el widget de slider de productos (`slider-coleccion-productos.js`) para incorporar soporte de imagen/logo en el encabezado, alineación vertical precisa con los controles y mayor separación entre flechas:

1. **Soporte para Imagen/Logo en el Header**:
   - Detección automática desde CMS o desde cualquier item (`.w-dyn-item`) mediante clases como `.jypesa-scol-cms-header-img`, `.jypesa-scol-header-img`, `.jypesa-scol-cms-header-icon`, `.jypesa-scol-brand-img`, etc.
   - Soporte para definición directa en el elemento embed a través de atributos HTML (`data-header-img`, `data-header-icon`).
   - Integración visual dentro del bloque de encabezado con contenedor dedicado (`.jypesa-scol-header-img-wrap`) y estilos responsive.

2. **Alineación Vertical con Flechas**:
   - Ajuste de `.jypesa-scol-header-row` y `.jypesa-scol-header-content` a `align-items: center` para alinear armónicamente la imagen/logo, el texto de título/descripción y los controles de flechas a la misma altura.

3. **Mayor Separación de Flechas**:
   - Incremento del espaciado entre los botones circulares de navegación en `.jypesa-scol-controls-row` a `gap: 20px`.

4. **Demos Actualizados en Preview**:
   - Se añadieron nuevos casos de uso en `preview.html`: demo con fondo naranja, logo y textos estilizados, y demo con extracción automática desde elementos CMS.

## fix: add max-width 60vw and mobile row alignment with smaller arrow buttons in slider-coleccion-productos

### Descripción

- Se configuró un `max-width: 60vw` en `.jypesa-scol-header-content` tanto en desktop como en móvil para evitar solapamientos con los controles.

- Se redujo el tamaño de los botones circulares de las flechas en celular a `40px x 40px` (y su SVG a `40px x 40px`) con espaciado de `10px`.
