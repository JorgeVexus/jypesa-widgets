# Changelog — 2026-08-08

## feat: fix tab content width and add product order support in tabs-colecciones-productos

### Descripción
Se realizaron 2 mejoras clave en el widget de pestañas de colecciones de productos (`widgets/tabs-colecciones-productos/tabs-colecciones-productos.js`):

1. **Ancho Constante del Contenido del Tab (`jypesa-tabs-right-col`)**:
   - Se ajustaron las reglas CSS de `.jypesa-tabs-right-col`, `.jypesa-tab-content-panel`, `.jypesa-tabs-subgroup-section` y `.jypesa-tabs-slider-outer` asegurando `min-width: 100% !important`, `width: 100% !important;` y `box-sizing: border-box !important`.
   - En pantallas desktop, se eliminó la restricción `width: calc(100% - 520px)` a favor de un dimensionamiento flexbox fluido (`flex: 1 1 0% !important; width: auto !important`), garantizando que la columna derecha mantenga siempre el mismo ancho sin importar si una pestaña tiene 1 producto o varios productos.

2. **Ordenamiento de Productos por `jypesa-prod-order`**:
   - Se añadió la función helper `getProdOrderVal(itemEl)` para leer valores de orden numérico asignados a productos en el CMS.
   - Soporta clases CSS como `.jypesa-prod-order`, `.jypesa-tabs-prod-order`, `.jypesa-product-order`, `.product-order`, `.prod-order` y atributos HTML como `data-prod-order="1"`, `data-product-order="1"`, `data-sort-order="1"`, `data-order="1"`.
   - Al construir las colecciones y subgrupos, los productos son ordenados numéricamente de menor a mayor (`1, 2, 3...`).
